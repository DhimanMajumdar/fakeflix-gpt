
# 🎬 FakeFlix GPT

A Netflix-like movie recommendation platform built using **React**, **Redux**, **Firebase**, **Gemini AI**, and **TMDB API**. FakeFlix GPT offers an engaging user experience with personalized movie suggestions powered by Gemini AI, secure authentication via Firebase, and dynamic UI components styled with Tailwind CSS.

> ⚠️ **Note:** Due to TMDB API restrictions in India, the platform may not function when accessed via **Jio SIM data**. However, it works perfectly on **WiFi, LAN**, and **other mobile networks**.

---

> ✨ Live Site: [https://fakeflix-gpt-j9pd.vercel.app/](https://fakeflix-gpt-j9pd.vercel.app/)

## 🚀 Features

- 🔍 Movie & TV show listings from **TMDB API**
- 🎥 Embedded **YouTube trailers** in interactive movie cards
- 🧠 **Gemini AI integration** for personalized recommendations
- 🔐 **Firebase Authentication** for secure login/signup
- ⚡ Optimized frontend with **35% faster** page load times
- 📱 **Responsive UI** for mobile, tablet, and desktop
- 📊 Enhanced suggestion accuracy by **50%** using AI-driven preferences

## 📦 Installation & Setup

1. **Clone the repository**

   ```bash
   git clone https://github.com/yourusername/fakeflix-gpt.git
   cd fakeflix-gpt
   ```

2. **Install dependencies**

   ```bash
   npm install
   ```

3. **Set up environment variables**

   Create a `.env` file in the root directory and add:

   ```env
   REACT_APP_TMDB_API_KEY=your_tmdb_api_key
   REACT_APP_FIREBASE_API_KEY=your_firebase_api_key
   REACT_APP_GEMINI_API_KEY=your_gemini_api_key
   ```

4. **Run the development server**

   ```bash
   npm start
   ```
